# 韩叙剪辑 Agent · 朋友试用版 0.3.3

把你自己的视频和要求交给电脑上的 Codex，通过对话完成剪辑和修改。ChatCut Desktop制作可编辑时间线，剪映专业版完成画面、美颜、字幕、封面和最终工程。当前先面向Mac朋友试用。

**[下载最新版试用ZIP](https://github.com/hanxu66/hanxu-video-edit/releases/download/v0.3.3/hanxu-video-edit-0.3.3.zip) · [版本与下载说明](https://github.com/hanxu66/hanxu-video-edit/releases/tag/v0.3.3) · [完整开始指南](开始使用.md)**

## 第一次怎么开始

1. 下载上面的ZIP，完整解压；在电脑上的Codex打开“剪辑Agent朋友试用”整个文件夹。
2. 需要你自己的Codex、ChatCut Desktop和剪映专业版。已有的不重装；缺少的按[开始指南](开始使用.md)中的官方入口和对话提示处理。账号、软件与服务费用按你自己的实际界面。
3. 将下面这段话发给Codex：

```text
我第一次使用这个剪辑方法，请带我开始。请使用 ChatCut Desktop，可创建本次专用的剪映工程，别动我的其他工程。先检查连接和工程交付能力，再按默认效果做实际小样；需要我操作时一次告诉我一件事。
```

4. 告诉它视频在你电脑上的位置。第一次建议一条1–3分钟口播，或直播回放中明确指定的一小段。先看小样，再继续整条。
5. 直接说“美颜轻一点”“字幕大一点”“画面亮一点”等。需要姓名/title时提供你自己的文字；其他制作效果有默认值，也可以调整。

也可以通过GitHub的Code下载源码ZIP，完整解压后在Codex打开包含本README和AGENTS.md的文件夹，按同一段开始语句运行。不要只复制SKILL.md，配套参考和脚本需要保留。采用本项目文件夹入口，不要求把方法安装到全局目录。

## 这次试用什么

默认能力保留剪辑、画面构图、色彩、美颜美体、声音、字幕、姓名/身份文字和封面。先验证工具及工程交付路径，第一条小样会检查备份、重新打开和再次导出；发现缺口先处理，再做长片。

本机已用“上PPT、下真人”的直播回放完成真实切片、字幕/封面返修、同修订原生剪映工程、完整草稿目录在同机原路径恢复与再次导出。最终工程与视频、字幕和封面需保持同一版。

**仍需真实验证：**

- 另一位用户/另一台电脑的首次连接、字体和美颜资源复现，及完整口播首次流程。
- 跨电脑、不同路径的剪映工程迁移；Windows/Linux。
- 本用户版访谈、用户访谈、直播卡片、PPT/故事型动画与纯AI的各自完整实剪流程。方法入口已带上，方法存在不表示实测完成。

本轮优先用Mac上的短口播或指定直播片段开始。小样与成片的画面、声音是否合适，由使用者实际看听判断；本机技术检查不等于新用户验收或发布效果。

## 文件和反馈

原片留在你自己的电脑，将路径交给你自己的Codex；完成交付前保留原片和工作文件夹。本地处理仍可能使用联网转写/生成服务，以实际工具和授权提示为准。

反馈可用[试用反馈.txt](试用反馈.txt)，回到发包者的原微信对话。先提供版本、所处步骤和当前提示截图；字幕或声音问题带时间点。技术检查可让你自己的Codex完成。

本仓库和试用ZIP只含方法、参数、检查脚本与说明，不含作者账号、原片、成片、工程、试用身份、声音、字体或模型。剪映自己的草稿和缓存位置由软件管理，Agent会说明本次专用工程范围。
