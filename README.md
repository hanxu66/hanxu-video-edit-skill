# 韩叙视频剪辑 skill

把视频或稿件交给 Codex，通过对话完成剪辑。已有完整默认效果；看过实际小样后，可以说“美颜轻一点”“字幕大一点”“标题往下移”。

当前版本：**0.5.0**，同一 skill 适配 **macOS 和原生 Windows**。根目录的 `SKILL.md` 就是技能入口。安装一次后，在自己的本地剪辑工作目录中使用，无需把下载目录建成指定的 Codex 项目，也不用寻找隐藏文件。

本次补齐Windows首次上手、中文路径与编码、应用/字体/工具检测、项目依赖及字幕重建；保留原有泛白调色、安全区检查和完整默认效果，具体变化见[更新说明](docs/更新说明.md)。

## 安装

### 从 GitHub 安装

把下面这段话发给自己电脑上的 Codex：

> 请使用 skill-installer，将 https://github.com/hanxu66/hanxu-video-edit-skill 仓库根目录（版本 v0.5.0）安装为我自己的技能，技能名为 hanxu-video-edit-skill。若已有旧版，先保留旧版再更新，不改其他技能。请识别我的Mac或Windows系统，检查入口、当前工具和资源，带我开始。

### 已经拿到旧压缩包

这次只更新 GitHub，原先另行分发的 0.4.0 压缩包保持原样；要用本次改进，请直接把上面的 GitHub 安装/更新指令发给 Codex。旧包仍可完整解压后安装，里面含有 `SKILL.md` 的 `hanxu-video-edit-skill` 文件夹就是技能；把实际位置告诉 Codex：

> 请把这个位置的韩叙视频剪辑 skill 安装为我自己的技能：〈解压后的文件夹位置〉。若已有旧版，先保留旧版再更新。请检查安装结果，不要把素材或任务保存在技能安装目录。

以上安装操作由 Codex 完成，不需要手动移动隐藏目录。若安装后当前对话还没有识别到技能，在下一轮调用；仍未出现时重开 Codex 再调用。技能文件夹可以含有多个方法和脚本，它仍是一项技能。

## 开始剪辑

在 Codex 中打开自己准备存放剪辑结果的本地文件夹，发：

> 使用 $hanxu-video-edit-skill 帮我剪视频。原片在：〈自己电脑上的视频路径〉。请先检查当前需要的工具和工程交付能力，按默认效果做实际小样；需要我操作时一次告诉我一件事。

也可以先说“使用韩叙视频剪辑 skill 带我开始”，由 Codex 问当前必要的信息。安装目录与剪辑目录分开；换一个剪辑目录仍可使用已安装的技能。用户不需要理解 AGENTS.md 或编写配置。

完整流程：提供视频/稿件 → 识别本次场景并检查实际工具 → 保护原片工作副本 → 内容精剪 → 完整效果小样 → 对话修改 → 检查同修订成片、独立封面和可编辑工程 → 用户确认。姓名和身份内容用自己的，可以不额外显示；其余效果有默认值。

## 能剪什么

- 纯口播；访谈、单人访谈与用户访谈。
- 直播回放切片；从回放制作卡片式短视频。
- 真人加 PPT 型或故事型动画；从确认稿制作纯 AI 视频。
- 字幕、画面、色彩、美颜美体、音量、姓名/身份、顶部标题、封面和局部返修。

普通口播默认 1.1 倍，直播切片 1.2 倍，访谈从自然 1.0 倍校准。默认美颜美体、对比5/饱和3/高光-5/阴影3、主字幕13号、姓名10号橙色、身份7号白色等完整设置保留。音量20dB为原方法基线，先检查实录峰值再校准，避免削波；不把20dB一律叠加。直播身份/主题按场景方法。以上均可通过对话调整。

## 运行条件与交付

Mac与原生Windows使用同一套对话流程，由Codex按本机检查ChatCut Desktop与剪映专业版。Windows不需要照抄Mac命令、查隐藏文件或先装WSL。**安装 skill 提供方法与脚本，剪辑软件、工具连接、账户、字体及效果资源需在自己的电脑上具备。** Codex按当前步骤检查，缺项时给出具体操作；不把软件已安装当作连接成功，不自动购买服务。

Windows可以直接给`D:\视频素材\原片.mp4`这样的实际路径，中文和空格无需自己改名；Python、FFmpeg、字体和本地依赖的系统差异由Codex处理。首次用一小段素材检查完整效果和可编辑工程交接，避免整条剪完才发现当前连接不支持。技术适配与未实测范围见[双系统使用](references/双系统使用.md)及[验证范围](docs/验证范围.md)。

任务状态、保护副本、可配置缓存和输出放在用户自己的剪辑目录；安装目录保持只读。技能升级不覆盖旧任务。原片和未采用版本不会自动删除，视频不会自动上传或发布。转写/生成是否联网及费用按实际所用服务和账号说明。

交付包括视频、独立封面、字幕及约定的可编辑工程。完整剪映交接在精剪前检查，小样先走一遍工程恢复和导出；没有匹配工程时会明确说明缺口，不把扁平视频当工程。跨电脑的字体、效果资源和工程重连须在实际环境核对。

已核对项目见 [验证范围](docs/验证范围.md)。访谈特定风格及回放卡片既有版式等仍需对应样例核对；方法入口已保留，不将“有方法”写成所有场景已完成实剪验收。

## 直播切片时会检查什么

- 先看回放真实布局。上PPT下真人保留实际课件；若你要求选有截图、有画面的内容，会同时核对讲述期间的课件页面。
- 默认效果后仍查脸部高光、肤色和明暗层次。你可以直接说“脸太白了，只调调色”，无需判断该改哪个参数；先看实际对照，再决定是否采用。
- 顶部标题、字幕和封面分别检查目标平台安全区。靠近遮挡边界也会留出空隙，优先移动标题并避开脸部与课件；剪映预览和真实手机显示分别记录。
- 字幕、封面或调色返修会同步到当前原生工程，检查其余有效效果保持。实际视频由你确认后交付，不自动发布。

## 遇到问题

直接在原剪辑对话中给出时间点和修改要求。无法继续时，提供“当前步骤＋报错截图＋版本号”；无需先发原片、密码或整份私人日志。给你本技能的人也可以据此定位问题。
