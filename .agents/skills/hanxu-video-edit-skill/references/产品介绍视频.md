# 产品介绍视频

仅在使用者明确要求产品/课程/企业介绍时启用；动画、声音及导出仍按[动画视频制作](动画视频制作.md)或[口播剪辑](口播剪辑.md)，结果按[执行标准](剪辑执行标准.md)。

## 锁定产品事实与范围

继承已确认名称、对象、问题、内容、交付、价格、边界与真实证据；产品事实与表达材料由使用者提供/确认，不为视频另造权益、目标客户或经营结果。记录`video_category=产品介绍视频`、触发原话、目标时长、横竖范围、动画类型和视觉依据。类别与故事型/PPT型是不同维度。单条明确要求优先，当前此类短版以90秒内组织，先压缩文案再按本人认可声音节奏制作，不能仅把长片机械加速或截断。

## 介绍结构与声音

1. 开头按企业/产品官方介绍：用一句话讲清这是什么、叫什么、面对谁、解决什么问题。配套先呈现整体课程/产品模型，再展开局部；不沿用知识短视频的痛点钩子或悬念开场。
2. 建立“整体价值与模型 → 受众处境与具体卡点 → 关键问题和解决机制 → 学习/使用过程与成果阶段 → 可信反馈 → 主讲人/团队与参与入口”的紧凑叙述，按实际材料取舍。首页模型呈现输入、核心能力连接和可带走的成果，不以堆节点体现系统性。缩短时合并同类问题，保留问题到解法的逻辑，不只剩模块名或宣传口号。
3. 主讲人介绍用第一人称“我”，自然说明实践来源、经验与希望帮助的具体事情。使用客观、谦虚的措辞，不逐条朗读画面上的title、履历或头衔，不宣称未经证实的效果。需要正式介绍时，画面展示姓名、已核实的正式身份与履历，与口头讲述互补；不因不念title而删除屏幕履历。
4. 先核对当前官网或指定品牌的主色、logo原资产与实际使用，不仅从旧视频继承配色。按本人要求建立商务层级、克制对比和低刺激模块配色，不用大面积高亮底色、亮白卡片和无层级色块替代设计。允许加logo时置于左上固定品牌区，保持原比例、识别性和安全间距；具体色值与尺寸绑定当前对象。
5. 背景音乐按本人本次明确方向制作或选取，独立保留、配合节奏并让人声优先。照片与真实课堂素材服务讲解和证据，模型关系由动画承担。用户提出该类视频与动画形式时才使用，不自动替换其他视频画风。

## 知识关系的模型动画

1. 为每处流程、层级、调用、输入输出或反馈关系建立“原话 → 对象及职责 → 关系类型 → 开始状态/变化/落点 → 配音时码”映射。不只让几个词轮流出现，不将所有知识点画成同一种线性箭头。
2. 工作流、Agent、Skill按当前知识依据呈现：工作流组织完整任务与阶段；Agent推进阶段结果并调用Skill；Skill承载具体方法。用阶段展开、调用与返回、产物交接等动作显示职责，不画成三者互相升级、转化或可以替换的关系。知识依据与标准检查按实际讲述接入，反馈有明确返回对象。
3. 复杂关系先总览，再放大一项观众能识别的实际任务；随讲述逐步出现职责与调用，最后收束为简洁整体。避免一开始铺满多行多列的Agent/Skill节点与重复连线，不以增加节点证明系统性。全部类似知识点按各自关系选择流程、层级、对比或模型动画；动作跟随配音，关系线有方向和含义。文字帮助辨认职责，不用大段逐字稿替代图解。
4. 可以参考本人已提供/已授权的PPT及课程页面模型；先核对文字与当前有效知识。旧课件含失效架构、历史数字或旧名称时重绘当前逻辑，不恢复旧事实。原PPT是参考资产，不必将静态图片逐页播放。

## 受众页与双版交付

1. 开头概括受众；整体介绍后尽早用一张稳定画面，把职业/行业关键词、岗位及阶段与各自具体问题一一对应。围绕“哪些人想把自己的专业做成Agent”组织，沿用有效来源，不凭空增加行业承诺。配音概括，画面对应“谁—卡在哪里—本课处理哪个环节”，避免只列职业、泛化痛点或直到片尾才出现受众。
2. 两种画幅分别安排模型、受众关键词、照片、字幕和咨询入口；保留同一语义和配音时码。时长、模型完整显示及关键词同时可读均以实际导出为准。
3. 上传的模型、聊天记录、案例或账号截图先逐项归档并判断对应产品和阶段，再选用。原图节选保持原句和上下文，区分课程反馈、咨询反馈、账号展示与经营数据；不把咨询或求职结果移作本课效果，不从播放量推导课程因果。可匿名截取必要区域并保留原图，不生成虚构聊天界面，姓名、头像和联系方式不作无必要展示。
4. 对照[执行标准](剪辑执行标准.md)检查实际文件。声音听辨、导演审美、工程交接和发布分别记录，技术检查不代替本人采用。返修只使真实变化项及其下游失效。
