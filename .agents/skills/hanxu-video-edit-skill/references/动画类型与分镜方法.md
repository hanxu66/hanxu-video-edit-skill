# 动画类型与分镜方法

本文件是动画视频制作Skill的类型方法引用，也是口播局部动画的共同制作依据。这里只维护两类分镜方法；范围、输入选择与状态交韩叙视频剪辑 skill，原声剪辑、头像、字幕、工程和导出执行原主责Skill，结果判定读剪辑执行标准。

## 接收已选类型

使用本次已绑定的`animation_type`和`animation_type_source`，分别读取下列故事型或PPT型方法。类型、视觉画风、制作工具是不同维度；同一配色或同一代码工具均可制作两类动画。“PPT型”是结构化图解的类别名，不要求使用PowerPoint软件或生成PPT文件。

## 故事型

### 表达与视觉方向

- 用人物、物体或关系在时间中的连续变化解释内容：谁遇到了什么问题，采取什么动作，状态怎样改变。跨镜优先保留可识别的角色、任务或物体，让观众跟随事情的发展。
- 保留故事化表达的方法，按每条内容重新设计具体视觉。默认选择克制、成熟、适合专业经验与工作方法讲解的表达；可用有工作细节的编辑插画、文档／界面等专业信息动画、已授权真实素材与动画组合。只有实际内容需要时才加入相应素材，不强制收齐所有形式。
- 故事型不固定为圆脑袋、点状眼睛、几根线的人物、卡通机器人或单线条画法；清楚易懂不等于粗简、低幼。已有配色、字体和安全区继续沿用，不从颜色认可推导人物造型认可，也不以增加装饰细节替代合适的造型与动作。

### 制作方法

1. 读完整段内容，提炼问题、阻力、转折、行动、结果及真实关系；按原声的实际展开选择需要可视化的环节，不强套固定剧情或每句配一个新图标。
2. 把关系翻译成可见动作。选择能保持语义的角色、工作场景、物体或视觉隐喻，例如沟通偏差可以表现为同一份设计稿经过交接后逐渐走样，反复修改可以表现为版本退回、批注增加。隐喻是示意，不冒充本人真实经历或新增事实。
3. 用同一角色、任务或物体串起相关镜头，记录“原话／时间段、镜头开始状态、动作、结束状态、下一镜承接、必要文字、素材来源”；只在发生新的动作、视角或语义转折时换镜。文字辅助辨认关键对象与结论，不用标题、列表或卡片轮换代替主要叙事。
4. 按原声时码安排动作的发生、变化与落点。优先让对象的传递、修改、聚散、替换、交付等变化承担解释；需要数字、分类或精确步骤时可短暂使用图表或文字，并与当前任务衔接，不强行编成角色表演。角色与镜头复杂度依实际内容和素材决定。
5. 沿用当前可用、无需新增付费的代码动画与原生工程路线；素材已具备时可配合精细矢量、插画或真实素材。制作工具不决定视觉风格，不因“故事型”自动改为AI视频模型、购买订阅或上传新服务。代码直接控制图形、时间与运动，不能单靠使用代码声称具有故事性。
6. 继承已认可的表达与有效样式，针对新造型／场景且仍需审美判断的部分按原Skill制作代表片段；已认可的同一视觉方案直接继续。故事型认可不等于所有后续插画、封面或声音已经采用。

### 已有制作经验的使用范围

“想法中的纸飞机，经沟通变成纸船”可示意信息走样；“同一任务经过资料、判断、初稿、检查、交付和反馈”可示意工作过程。它们是已制作的分镜例子，不是每条故事型视频必须复用的题材、人物或画风。历史小样能证明对应片段已制作，不能证明所有故事型视觉成熟度、全片采用或平台效果已经通过。

## PPT型

### 表达方向

以观点、对比、层级、步骤、流程或模型的结构化图解辅助理解，沿用此前的解释动画方法。文字、卡片、连线、箭头和图形可以按信息关系出现、强调和切换；不要求连续角色或一件任务贯穿全段。

### 制作方法

1. 从原话提取需要看懂的判断、项数、层级、顺序与连接关系；先确定信息结构，再选择对比、流程、模型等版式，不把所有内容统一套成同一组卡片。
2. 把必要文字与图形排成清楚的稳定画面；同组并列概念在主题引出后共同呈现，步骤和因果按原声逐步展开，保留足够阅读时间。
3. 动画用于引导阅读、突出变化或解释关系；按原声安排进入、停留、强调与退出，不把大段逐字稿搬到屏幕，也不为堆动效延长气口或改写语义。
4. 复用已认可的颜色、字体和安全区；不同信息结构制作相应版式，原生资产、文字与图形继续可编辑，最后回到原Skill的合成、交接和导出步骤。

## 共同交接

分镜计划携带已选类型、选择依据、局部／全片范围、视觉依据、原声区间与实际资产。类型改变时只让受影响的动画、合成、导出和复查失效，保留未变的原声与其他有效检查点。主原声、字幕、头像和动画同步仍由原主责Skill落实；最终回读剪辑执行标准中对应类型的实际结果要求。
