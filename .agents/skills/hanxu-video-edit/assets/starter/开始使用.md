# 剪辑Agent朋友试用｜0.3.3

这是韩叙当前剪辑方法的朋友试用包：在你自己电脑的Codex里通过对话执行，ChatCut Desktop负责可编辑时间线，剪映专业版用于完整效果与工程收尾。你提供素材和判断，Agent处理当前能做的操作并给实际小样。

## 先开始，不用通读

完整解压本包 → 在Codex打开整个文件夹 → 发送下面这一句 → 提供你电脑的视频位置。

> 我第一次使用这个剪辑方法，请带我开始。请使用 ChatCut Desktop，可创建本次专用的剪映工程，别动我的其他工程。先检查连接和工程交付能力，再按默认效果做实际小样；需要我操作时一次告诉我一件事。

推荐首次选自己拍的一条1–3分钟口播，或明确指定直播区间。无需先填姓名、身份、全部效果参数。其他场景也可提出，本版访谈、卡片、动画和纯AI尚未完成跨用户的完整实剪验证。

## 需要哪些东西

- 一台Mac，以及你自己的原片。当前只在作者Mac实测；Windows/Linux未完成本方法验证。
- 可登录和使用的Codex桌面入口。新版官方入口可能显示在ChatGPT桌面应用中，选择Codex并打开本机文件夹；网页、手机端和云环境不是本次试用路径。安装与登录见[OpenAI官方开始说明](https://learn.chatgpt.com/docs/quickstart)。
- 同一台电脑上的ChatCut Desktop。按[官方下载说明](https://chatcut.io/docs/desktop-app)选择与你的芯片对应的安装包，完成系统安装提示，打开并登录；已有的不用重装。
- 完整效果与可编辑工程收尾需要剪映专业版。在[剪映官网](https://www.capcut.cn/)选择桌面专业版，安装后至少打开一次。不要把网页版或手机版当成这次桌面工程的替代。

软件、账号权益、正版字体和美颜资源不包含在这个方法包里。模型/服务费用按自己的账号与当前界面核对，不承诺全程免费；首次可以先检查环境，再决定是否继续。不要把密码或验证码发到对话里。

## 安装之后怎么连接

1. 打开ChatCut Desktop，打开一个本次试用专用的新项目，保留桌面端运行。
2. 在同一台电脑的Codex里选择本包解压后的整个文件夹。第一次不需要运行终端命令，也不用编辑隐藏文件。
3. 发送上面的开始语句。Agent先检查它是否真的能读到目标项目，不能仅因为应用已安装就说连接成功。ChatCut桌面端会尝试注册本地连接；需要时按官方桌面说明里的连接状态或Reconnect处理。不要用托管网页版插件代替本地桌面连接。[连接说明](https://chatcut.io/docs/desktop-app)
4. 新装连接后如果当前聊天没有工具，在同一个工作文件夹新建对话，并说“继续刚才的剪辑试用，先检查连接”。连接实际可用后再继续，不反复重装。
5. 需要Agent操作剪映界面时，在桌面应用的Plugins中查找Computer Use，按提示安装或启用；Mac上的屏幕录制、辅助功能以及目标应用访问权限由你在实际弹窗里确认。[官方设置说明](https://learn.chatgpt.com/docs/computer-use)

安装软件和插件是你的电脑上的明确设置动作，不由方法包静默执行。若账号或地区没有相应能力，Agent说明当前能做什么、保留进度；不用无限重试。也可根据它列出的明确步骤，在剪映中手动收尾。

## 一次完整剪辑会怎样进行

1. **接收素材。** 给本机视频路径及一句要求。Agent记录已给信息、保护工作副本；读取或导入前所需的文件访问按实际提示处理。
2. **确认这次怎么剪。** 已说“纯口播”“直播切片”就直接采用；需要动画、卡片等且意思不清楚时才补问。直播可给起止时间，也可以要求先挑候选，二者工作量不同。
3. **做默认效果小样。** 整条精剪前先查剪映连接和交接能力；第一条小样同时检查工程保存、备份、重新打开及再次导出，发现缺口先处理，避免整片做完才卡住。包含场景适用的剪辑、声音、画面、色彩、美颜、字幕样式和封面。身份未定可以先不给身份文字；需显示姓名和身份时只用你提供的文字。特定字体或效果在你电脑上能否复现要看实际小样。
4. **通过对话调整。** 可以说“美颜轻一点”“姓名大一点”“字幕改成白色”“02:15这句留下”“先不加身份”。没要求改的效果保持；单条偏好不会自动变成长期设置。
5. **出片并检查。** Agent提供实际视频、独立封面、字幕源和能交付的可编辑资料，告诉你真实检查范围。你看画面、听声音，决定采用或继续改。
6. **交工程和接续。** 原生工程须与最终视频同修订，并在本机重新打开、核对素材和效果。只有旧草稿或部分可编辑源时会标明未完成；包里有字幕/封面源不等于完整剪映工程已齐。暂停时说“这条先到这里”，以后在原文件夹继续即可。

剪映原生草稿通常由软件管理，可能写在工作文件夹外。需要此步骤时Agent先说明本次试用工程及媒体的位置和操作范围，按你给的权限处理；不会拿你其他草稿做实验。严格限定只写工作文件夹时，此阶段可能保持待完成。[工程交接说明](https://chatcut.io/docs/export-capcut-jianying)

## 文件放哪里，需不需要上传

- **这个方法包**：保存到自己电脑，完整解压后在Codex打开文件夹。不用上传GitHub，也不用上传到一个“Agent后台”。
- **你的原片**：留在电脑上，把路径告诉Codex；不需要为了试用发给韩叙。确认已保护工作副本、完成交付前，保留原片。
- **网络处理**：本地文件不等于全程离线；Codex及转写/生成等服务可能发送所需内容。遇到服务或授权提示按自己的材料情况决定；第一次建议使用可用于测试的非敏感素材。
- **结果**：Agent给出本条实际保存位置和文件链接；它不能自动把视频发布到社交平台。
- **反馈**：直接在原来的微信私聊回给发送者，先给卡点截图/提示文字和版本；原片或完整日志仅在确有需要时另行确认。

## 卡住时直接这样说

- 看不懂设置：“我现在卡在这里，只告诉我下一步点哪里。”
- 找不到方法：“请读取本文件夹的AGENTS.md，以及.agents/skills/hanxu-video-edit/SKILL.md，继续本次试用。”
- 没连接：“请检查ChatCut Desktop本地连接，保留进度，不要重复安装。”
- 只有图没视频：“请说明这张小样验证了哪些效果，还差什么。”
- 工程不对：“请核对工程与最终字幕是不是同一版，重新打开实际检查。”

仍然不通，就在原微信对话发卡点截图，不用自己折腾内部配置。反馈可以用同文件夹的“试用反馈.txt”，不需要额外注册表单。
