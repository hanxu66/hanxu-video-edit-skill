# 路由、修订与检查点

以本条原素材或已确认稿开工。对象ID由Codex在本项目命名；不要求内部经营系统、选题库、私人样本或公司状态工具。内容主题由使用者确定，不能套作者个人AI业务方向筛选素材。

1. 先锁定并保护当前原素材，默认效果读取[默认效果与调整](默认效果与调整.md)，用户明确要求覆盖对应项。锁定来源、形式、当前修订、已认可项、反馈、交付范围与输出位置。新任务先完成本地预检。`重新剪辑/重剪`从原素材和新空白工程开始；`修改/返修`沿匹配的当前可编辑工程，只改变指定项。
2. 真人任务按实际场景完成导入、转写、内容取舍、剪点与字幕文字：独立口播读口播方法；单人/用户访谈读[访谈方法](访谈剪辑.md)；回放切片和回放卡片式短视频读[直播方法](直播切片剪辑.md)，保留源时间码和候选/选定范围。动画任务携带已选类型和实际原声区间；纯AI从确认稿直接进入动画与配音，不要求补拍摄事实。
3. 正式范围使用ChatCut可编辑草稿交接剪映，核对素材、时长、实际速度与不支持属性；剪映收尾包装与正式导出。原生动画审看使用ChatCut原生工程及导出。两种交付范围明确，不以扁平MP4冒充整条可编辑工程。
4. 每大步骤先读本条对应方法与执行标准，按真实工程/时间线/波形/导出物检查。记录读取时点、修订、实际参数/结果、证据时间码、仍有效/已失效的检查点。单帧、字段或脚本PASS不替代实际画面/声音。听辨受限保留待试听项。
5. 反馈逐项转成变化项、恢复目标、失效项、继续有效项。上游内容或源改变才走新ChatCut修订及真实下游；字幕错字、局部剪口、参数、身份、封面在当前最终工程修。仅封面变化不重导MP4。每次更换草稿重新核对实际链接，不继承另一工程的生效证据。
6. 单次操作回读无效就停止重复点击，确认当前对象与最后成功点。结果未知不重发导入或导出。软件确有故障且已保存/未保存范围明确时按原方法最多恢复一次；10分钟仍不恢复就保存单一断点。进程存在或资源不足不自动等于软件卡死，不清理其他文件或更改系统设置。

一批多条逐条完成，方法和检查均绑定本条对象。首次交付待本人审看，采用确认与发布分开。本版本不自动发布、回收账号数据、提醒、上传网盘或删除媒体。出错/停止保留源文件和可恢复进度，清理另按使用者指令。

用户暂停单条后，保存并等待明确恢复；素材缺失仍可登记暂停、保留已有交付。默认方案升级不自动应用到暂停条目。无关维护Hook不进入剪辑对话或工具分支。
