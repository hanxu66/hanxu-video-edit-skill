# 更新说明

## 0.4.1 · 2026-10-21

根据本机直播切片的实际制作、返修及用户确认补充检查。本次仅更新GitHub方法和使用说明，未重新制作或上传分发压缩包；完整默认参数、八种场景和脚本能力保持。

| 实际遇到的问题 | 现在怎样处理 |
| --- | --- |
| 套过默认效果，脸部仍泛白、缺少立体感 | 在小样和最终导出中检查高光、肤色与暗部；按素材减高光/白色、补对比和阴影层次，同时保护课件可读性。单例参数只作参考，不改所有人的默认 |
| 顶部标题没有明显越界，却贴近抖音遮挡区 | 小样和导出前均实际打开目标平台预览，检查完整字形及阴影。优先下移到留白，避开课件和动态头顶；原生字段与同修订导出一起核对 |
| 上PPT下真人，或要求话题期间有真实图片 | 按源画面校准布局，候选时间码同时核对课件实际有图；用户没有这项选段要求时不强制排除纯文字页 |
| 完整英文词组在剪映自动换行 | 在安全区允许时先校准该卡文本框，不缩小默认字号或使用负字距；仍超宽时按原声语义分卡，复查邻卡和实际导出 |
| 独立封面与工程封面不同步 | 核对封面、当前草稿和当前成片的修订；清除旧模板残字，封面安全区独立检查，不把播放截图当主封面 |
| 工程能导入，却恢复错倍速 | 打开后核对实际速度、剪点和媒体，并试导出；失败备份不交付。完整目录快照只按实际验证范围说明，不宣称跨电脑即开 |
| 只改画面，却重导改变音轨或末帧 | 核对未变的字幕、时间和声音，证实来源与边界后才做必要流复制修正，保留原生原件；不冒称音频已听辨 |

具体执行见[常见问题与局部返修](../references/常见问题与局部返修.md)、[直播切片剪辑](../references/直播切片剪辑.md)与[最终工程交付](../references/最终工程交付.md)。这些方法接到技能入口、小样和导出检查，不能只在问题说明中存档。

已完成的本机效果验收与尚未完成的新电脑、真实手机平台和各场景验证，分别见[验证范围](验证范围.md)。公开仓库不含试剪原片、成片、身份信息或本机私有路径。
