# 验证范围

本次更新将既有剪辑方法从项目包改为独立 skill；不重做剪辑方法，不使用测试项目的私人素材和身份作为新用户默认。

- 方法与默认：逐文件对照既有版，保留全部场景、执行标准、默认参数、美颜美体资源标识、声音/字幕/封面及可编辑工程规则。
- 独立性：在作者测试项目之外的独立目录中解压和安装；不借用项目根目录AGENTS.md或旧session，以绝对技能路径调用脚本，资源从安装位置读取。本次已通过，回执见[verification.json](verification.json)。Codex原生扫描器在两个工作目录实际识别到独立安装位置的技能；使用目录级注册验证发现机制，未改作者的全局技能安装。
- 隔离：两个工作目录分别初始化、选择场景和调整参数；身份和任务不相互继承，安装目录不写入任务、依赖或缓存。
- 环境缺口：缺少实际连接和原生工程证据时，检查应报告待处理项，不伪造通过。
- 交付工具：以专用技术样本核对交付打包、异地目录校验和字幕源重建。技术样本只验证脚本，不替代真实剪辑效果验收。

已有实际依据包括本机直播切片的原生剪辑、字幕和封面导出，以及同机同路径的完整草稿目录恢复。此前原生jypack恢复曾丢失倍速，失败包未作为最终工程；此限制和替代验证流程保留在方法中。

尚未验证的范围：另一位用户/另一台电脑的完整制作；Windows/Linux；所有软件版本和账户资源；一般访谈全部风格、回放卡片既有版式、各类AI视频的逐一端到端成片；实际手机平台安全区与人工声音听辨。首次小样在用户实际环境确认这些适用条件，不能用本次脚本检查替代。
