# 口播剪辑 Skill｜ChatCut粗剪＋剪映收尾

- 标识：`short-video.skill.talking-head-edit`
- 所属Agent：[剪辑](路由与检查点.md)
- 执行标准：[剪辑执行标准](剪辑执行标准.md)
- 适用：使用者提供的单人口播原片，或明确要求的局部辅助动画；动画主画面和文字配音转[动画视频制作](动画视频制作.md)。

本Skill只定义剪辑动作、工具、参数、操作安全和交接字段，不作通过／失败判定；判定只读剪辑执行标准。

## 触发与输入

- 使用者提供单人口播原片并要求剪辑、返修或重剪时触发。
- 输入锁定：原素材、对象ID、实际口播、参考稿、当前修订、已认可项、反馈和交付目标。参考稿不得覆盖实际说出的内容。
- 接到韩叙视频剪辑 skill传入的辅助理解动画要求时，将本人原话、`animation_type`、`animation_type_source`、指定段落／时间点、动画范围和头像要求记入本对象运行记录，读取[动画类型与分镜方法](动画类型与分镜方法.md)的已选类别，再按第六步对应模式执行；没有指定段落时按实际口播选择需要展示关系的环节，不额外要求本人逐段选定。新任务只要求加动画而没有类型且无同对象继承记录时，补齐故事型／PPT型选择后才制作动画；未要求动画的普通口播不增加类型选择。
- 接到动画主画面、文字配音或本人动态圆头像任务时，将本条稿件、原声／录音、已认可样式与来源交给[动画视频制作Skill](动画视频制作.md)，不在本Skill重复执行动画制作步骤。

## 统一读取与操作规则

- 工具能力依据：[ChatCut Agent Plugin](https://chatcut.io/docs/agent-plugin)支持导入、裁剪/排列、转写/字幕和可编辑交接；[可编辑剪映/CapCut草稿](https://chatcut.io/docs/export-capcut-jianying)是ChatCut Desktop专属交接，不支持属性必须在剪映重建并复查。文件记录该能力不等于当前任务已加载MCP，仍须在第一步做运行时检查。
- 进入下面每一个大步骤前，先读执行标准的对应章节，再读本Skill该步操作；操作完成后再读执行标准复查，通过才建立检查点并继续。
- 连续剪辑多条口播时，对第二条及以后每条重复本Skill的完整步骤门：本条本步重新读取韩叙视频剪辑 skill、本Skill对应步骤和剪辑执行标准，完成后重新读取同一标准并与本条实际产物核对；把文件读取、复读、发现问题、修正和复查写进本条对象运行记录。上一条已读、已通过或当前批次做法相同，都不能替代本条证据。
- 当前步骤内已有明确清单的同类操作成组执行，不每点一次就截图、OCR或重读全文。
- 不因单条反馈修改共享方法或扩大本人授权；先修本条，偏好与实际证据保存到本项目。长期设置只在用户明确要求后更新本地配置，不改作者正式系统或全局规则。
- 对约10至15分钟原片、目标约3分钟成片，AI有效剪辑时间以3小时为目标，正常波动2.5至3.5小时。分别记录`ChatCut语义判断`、`剪映实际操作`、`软件/工具等待`和`返工`；有效时间达3小时仍未交付时停止新探索，保存检查点并说明剩余项和原因。
- 参考转写默认只生成一次；内容锁定后的正式字幕默认只生成一次。只有原素材、保留内容或时间码真实失效时才重新生成。
- 普通原口播固定主线为：`ChatCut锁定内容并完成用户所选倍速、剪点、气口与字幕文字 → 导出可编辑剪映草稿 → 剪映批量应用人声音量与美颜美体、完成调色和文字包装 → 导出前在时间线验收 → 唯一一次计划内正式导出 → 成片复查`。原视频改为动画主画面时先完成本条原声内容剪辑，再交动画视频制作Skill排布；文字配音直接由该Skill执行，不对已发布头像素材重复应用统一倍速与美颜美体。
- 新制作普通口播已要求局部辅助动画时，在上述主线中采用`代表片段校准 → 上游完成全部辅助动画 → 最终可编辑交接 → 整条基础参数与正式字幕`的接续，具体按第四步的辅助动画交接方法执行。既有最终工程的局部返修仍按返修影响范围处理，不因此重建上游。

3. 使用者说“这里被增加了错误的美颜预设”等描述时，如果没有明确要求换成另一个预设，目标是撤销这次误加并恢复修改前状态，不得自行推断为应用`本人选择的美颜预设`或任何其他预设；修改前状态无法可靠恢复时停止并报告具体缺口。
4. 收到内容、字幕或节奏反馈时，对照本条原片和修订记录源句/时间、原删改理由、反馈原话、最终处理、归因及复查项。区分误删、漏删、转写错误、个人偏好、新要求和未知原因；不将一次偏好升为通用方法。仅检索本项目使用者已确认反馈，记录相关项采用/不采用的理由。
5. 只有使用者本次明确要求修改美颜／美体，或本轮新增、替换、重新导入原片使相应检查点真实失效时，才进入第五步修改对应参数；否则美颜／美体保持不变。

## 新视觉形式的代表片段预览

## 常见错误与无效操作止损

- **常见错误：把第一条的规则读取和检查沿用到下一条。** 第二条开始前重新锁定本条对象与原片，每个大步骤独立预读、操作和复读标准；漏读或漏检时补做真实检查，不补写虚假的历史读取。发现偏差先修当前步骤并复查，把具体缺陷与修复记入该条对象运行记录；可泛化的原因仅记录本项目，待使用者明确要求后再维护其本地设置，不把一次失败直接写成所有视频的新默认版式。
- **常见错误：用“字幕单行居中、身份文字存在”代替最终版式检查。** 导出前后均用本条实际合成画面核对：字幕相对人物下巴/上身的位置，并缩到手机观看尺寸检查实际可读性；身份块核对在人脸侧面还是错误地跑到顶部、已启用身份各行左边缘是否一致，以及文字本体和阴影是否贴边或裁字。旧字号字段、逐卡中点统计和文字轨存在只能证明各自字段或存在性，不能替代这几项视觉回读；任一项缺证据或未通过剪辑执行标准时，不给包装`通过`，应在本条记录写明时间码、画面证据与失败项。
- **常见错误：用固定字数或平均时长机械切字幕。** 先按整句意思确定完整词组，再用实际转写词头、原片与时间尺定位每次切换；长句优先在自然语义边界拆分，不能为了满足字数把一个词组截开。逐卡语义回读与真实渲染检查分开记录，单行不等于断句合理。
- **常见错误：把轨道相接当作气口已净。** 全片接缝清单须覆盖片段内部，以及相接片段两侧保留下来的源静音和呼吸。本人反馈某处只是例子时，按其明确范围检查全条；每处记录前后原话、实际源边界和修复后时间码，听辨限制不取消可执行的波形与时间尺复核。
- **常见错误：把异常描述扩大成新参数指令。**“误加了某个预设”不等于“请换成流程默认预设”；先恢复原状态，不能让常规生产参数覆盖当前返修范围。
- **常见错误：界面无变化仍连续点击。**任何参数操作完成一次后，必须重新选择受影响对象并回读字段或可观察状态；回读未变化、对象不明确或结果不稳定时，本次操作判为无效。
- **常见错误：文件选择器误选相邻素材。** 导入原片、封面或成片用于复查时，点击“导入”前回读当前选中项的完整文件路径；列表坐标或一次点击不能代替选中状态。选错时先确认误入素材没有进入时间线，再通过完整路径重新选择并回读，记录该次误选及处理结果。
- **常见错误：字幕输入失焦后退格删除了时间线对象。** 修改前核对当前字幕的文字和时间码，锁定无关轨道，并确认文本输入框确实处于编辑状态；输入焦点丢失就先恢复，不继续发送退格或删除键。可靠的原生文字字段可直接设置并回读，不依赖连续盲打。误删或改到相邻字幕时立即原生撤销，核对受影响文字、字幕数量和时长恢复后再继续，不清空整条字幕轨重做。
- **常见错误：校准草稿先做整条包装，动画交接后再做一遍。** 校准只处理能暴露本条字体宽度、身份位置和动画分区的代表片段；整轨音量、美颜美体、调色、正式字幕和完整检查留到最终交接草稿。工具确需重新交接时，保留校准结果与上游有效素材，只重建真实失效项，不能把旧草稿的字段检查冒充新草稿已生效。
- **止损要求：**一次回读证明操作无效后立即停止同一种点击，不得改为逐片段重复、密集坐标点击或长时间盲试。先确认当前对象、作用范围、工具能力和最近有效检查点；仍无法可靠生效就记录阻塞，不把尝试次数当作完成证据。
- 止损后按下节区分控制失效、应用未响应和资源不足；不能把三者都交给重复重启，也不能在结果未知时重发添加素材或导出命令。
- **禁止行为：**未锁定返修范围就进入美颜面板；仅因Skill中存在美颜步骤就在局部返修中重新应用预设；用“已经点过”“界面短暂高亮”代替重新选中对象后的字段回读。

3. 窗口仍可操作时先原生保存并确认保存完成，再正常退出重开。需要系统强制退出时，本对象最近保存、最后动作及未保存范围必须已核实，并具有系统明确“未响应”，或正常退出未完成且主窗口连续观察失败的实际证据；后者记录为控制/退出失败，不能冒称系统已判定未响应。未保存范围不明不强退。恢复按Agent的一次重启及总时限执行，不循环试错；资源不足先暂停依赖空间的导出，不盲删缓存、原片或其他项目文件。

1. 使用ChatCut的文字驱动A-roll编辑实施已锁定清单：成组删除口误、失败尝试、失败开头、同词重复、同义重录和无增量句，按锁定顺序重排完整语义单元。
2. 不拼接不完整半句制造新表达；保留后版重录时，前版独有的必要主语、设置、转折和承接不得误删。
3. 内容顺序锁定后，在ChatCut只选择主口播轨的全部A-roll片段，不包含字幕、MG动画、BGM或其他轨道；一次性把所有口播片段设为`用户所选倍速`并让后续片段随时长变化顺移，不逐片段重复设置。
4. 回读主口播轨片段数、总时长和每个实际生效片段的速度，确认全部为`用户所选倍速`后，才以这条最终速度时间线继续处理气口和字幕时间。
5. 在用户所选倍速时间线上建立完整接缝清单，覆盖每句话和半句话结束后的全部停顿。逐处删除两段有效语音之间的全部静音空白，使前一片段结束帧与后一片段开始帧直接相接，不再保留`0.1秒`、`3帧`或功能停顿；同时结合转写、波形和嘴型微调源片首尾，保留完整词头、词尾与音节，不使用叠音、交叉重叠或重复播放掩盖接缝。
   同时单独定位咳嗽、喷嚏、突发叫声、无关画外音等明显较大且中断表达的非正常声音；这类声音可能没有转写文字，不能因转写无异常而漏过。结合原片、波形和前后有效字音确定最小删除区间，移除声音及对应中断画面，闭合接缝，并同步受影响字幕、动画及其他后续轨道。保留正常表达和有效信息，不把正常语气或有意义的人声当成噪声。交接后发现少量此类遗漏时，在当前可编辑剪映工程局部修正，不重建整条上游；声音与有效字音重叠、无法安全分离时保存具体区间并报告，不盲删字音。AI实际听辨不可用时沿用已确认本人反馈定位并记录限制，不宣称已听查全片。
6. 修正转写与字幕文字中的专名、错字和漏字，但不在这一步做最终字体、字号、字色、安全区位置或姓名/title。
7. 每次文字时间线修改通过ChatCut自身验证后立即应用，然后重读新的实际时间线，检查错删、断句、语义、顺序、用户所选倍速，以及全部接缝是否为`0帧空白且字音不重合`。
   交接前单独列出工具产生的1至3帧碎片、无对应保留词语的片段、与相邻片段重复的源区间，以及转写字词异常长而包含停顿的区间。逐项结合源词头词尾、完整句法、波形和时间尺判断，去掉失败重录残词或重复播放，保留正常短音节；短片段长度只触发复查，不作为自动删除阈值。将清单、处理理由、实际源区间及复查结果绑定本条修订，不能用工具验证成功代替语义检查。
   已知咳嗽等异常的定位、实际编辑和声音结果分别登记。只有疑似动作、波形或删除了若干帧时，只记已编辑区间；没有实际听辨或本人对当前修订的消失及前后字音确认，不报告“声音已清除”。实际听辨不可用时如实标记跳过；已有本人确认直接沿用，不重复索取。

## 第四步：ChatCut交接前检查与剪映草稿导出

1. 按执行标准完成ChatCut交接前检查，对照文字层锁定清单回读实际保留内容、总时长、片段数、顺序、全部口播片段的`用户所选倍速`、气口清单、字幕文字和可追溯原素材。
2. 保存新的ChatCut修订。在ChatCut Desktop导出面板选择剪映专业版可编辑草稿，回读`Imported`与`Not supported`清单，将后者写入剪映重建清单；`用户所选倍速`必须由ChatCut完成并作为交接项核对，不把它留到剪映常规收尾时重新设置。
3. 每次导出使用新草稿/修订名，不覆盖旧剪映草稿。打开新草稿后回读素材链接、时间线、总时长、片段数、全部口播片段的`用户所选倍速`和不支持属性；把回读证据交执行标准判定，结果为`失败`时回ChatCut或停在交接阻塞，不在剪映逐片段补救上游交接错误。

### 辅助动画的代表片段校准与最终交接

- 仅适用于新制作且已要求局部辅助动画的普通口播。先用本条真实代表片段在剪映校准最终画幅与分辨率、字体与字幕宽度、姓名/title及字幕占用区；只设置试做范围所需参数，不对全口播轨批量美化、铺满正式字幕或做全条检查。保存同对象的字幕小样检查点及动画制作约束，标明校准草稿不是最终交付草稿。
- 依据这些约束在ChatCut完成全部辅助动画并核对主口播不变；常规制作优先将动画作为独立媒体轨随官方可编辑草稿一起交接。最终交接记录口播源区间与速度、动画段数、实际起止帧、层级和声音来源，进入剪映后回读实际结果；工具导出面板未展示支持清单时，记录未展示及可独立核对项，不能补写成已逐项读取。
- 全部动画已到位且最终交接检查通过后，才在该最终草稿执行第五步整条基础参数和第六步正式字幕、身份包装及全量检查。动画添加无效时先按止损条款恢复，不能在已完成全条包装后反复换草稿；确需换草稿时，记录真实失效范围并在新草稿重新验证，不能省略必要重建。
- 原生当前工程已能可靠加入动画、或只是既有成片局部动画返修时，沿用该有效工程与未失效的检查点，不强制回到上游。校准样式可复用，旧草稿的生效状态不能跨新草稿直接继承。
- 第一次在新环境或新导出能力中使用动画时，先用一个真实代表动画验证可编辑交接，核对媒体可达、层级、入退场帧、音源和口播轨不变；已有同能力的有效交接记录可复用，只有相关版本、介质或能力改变才重新试交接。原生动画属性不支持时，只将动画自身渲染为独立媒体后走官方可编辑交接，保留可编辑口播与动画源，不扁平化整片；透明/合成方式必须与已确认样式相容，不为工具方便改变版式。
- 当前剪映添加动画一次无效即停止该路径；先核对是否已添加，结果已知且恢复后仍无可靠添加能力时，新制作在全条包装前切换上述独立媒体交接。已完成包装的工程先保留并尝试现有可靠原生局部操作；确需重交接才保存旧工程和失效清单，不在两个工具间反复往返。缓存标识或工具哈希只有口径明确相同时才与文件SHA256比较；来源疑问核对真实路径、同算法字节哈希、时长与同源画面，不因不透明缓存ID不同重复登记或转写。

## 第五步：剪映批量人声音量、美颜美体与调色

新制作辅助动画口播以第四步完成的最终交接草稿为本步对象；局部校准不提前执行本步全轨操作。

1. 回读上游用户所选速度，不重复倍速。默认1.1；读取本条有效配置，主口播人声音量字段默认直接设到20dB，不叠加。用户明确修改后用其本条数值；null只用于明确保留原值的任务，不能作为新用户省略音量处理的默认。
2. 默认音量字段与源片峰值、LUFS、真峰值是不同口径。回读实际值和全部目标片段覆盖；真实声音异常按已确认要求处理和复验，不因字段正确冒称声音合格。
3. 美颜默认使用[默认效果与调整](默认效果与调整.md)及参数快照的完整美颜组。已有同参数预设可复用；其他电脑须核对对应效果资源并复现，不能只查一个私人预设名。用户关闭或局部调整时按本条覆盖值执行。
4. 美体同样默认执行快照完整美体组，支持用户关闭/局部调整。纯动画无人物的部分不执行。默认参数不可用时报告缺少的实际资源，不能静默跳过。
5. 样式执行、实际覆盖和视觉结果分别检查。新用户完整默认小样包含美颜美体，不能只有字幕/身份。返修不涉及美化时保留原有效检查点，不重设无关参数。
6. 调色检查对比、饱和度、亮度/曝光、高光、阴影、黑色和可用自然饱和度；默认采用原方法同场景起点5、3、0、0、-5、3、0、0，再按本条代表明暗/肤色校准并记录。用户可修改单项，画面构图/裁切/人物大小同时纳入小样，不把美化免检扩大为画面免做。
7. 本步通过后保存`基础参数检查点`：绑定对象/修订、实际工程身份与当前路径、口播轨及全部片段的覆盖清单、源区间/速度、画幅/分辨率、各参数目标与实际字段、证据和原生保存完成时点。后续不逐小节重复打开参数面板；恢复软件或重命名不自动重设。新增/替换片段只让相应片段的参数覆盖失效；音频剪点/调序使相关同步检查失效，不自动改变仍有效的美颜/调色；画幅改变让坐标、安全区及包装检查失效，不自动改变声音增益。新导入草稿的参数生效证据必须重建，但先检查实际缺项，已实际保留的属性回读确认即可，不机械全部重填。每次续做将各项记为`沿用且依据仍有效／需核对／已失效需设置`，只处理后两类，不能用重新填写代替状态判断。

## 第六步：剪映最终字幕与文字包装

1. 在用户所选速度的最终时间线上重新生成、导入或对齐正式字幕；ChatCut时间码只作文字与参考，不直接宣称已同步。
2. 主字幕默认三极宋黑体超粗、剪映13号、白色#FFFFFF和深色阴影，按本条覆盖值调整；先核对本机字体和真实小样。字体实际生效、画幅、缩放、宽度和身份占用确定后再做全条分卡；最长中文、英文词组及身份同屏均需核对，不按字数猜测。
   字幕字间距保持剪映默认值或已确认字幕预设中的原值，不手动设负值挤成单行；过长时按词组和完整语义拆成前后两次显示，切换时间对齐实际词头，不改动口播。先整理前后文字与时间清单，再成组执行。小样通过不代替最终全条检查；后续只有少量长卡时在当前工程局部修复，不清空全轨重导。字体、画幅、缩放或可用宽度真实变化时，重新校准并复查受影响字幕；字段未变不重复分卡。步后将全部字幕的实际渲染与语义分卡证据交执行标准判定。
3. 读取本条show_identity。false则不新增姓名/title并跳过其检查；未决定则通过对话问一次。显示时仅用本人填写/认可的display_name与title_lines；可复用其实际存在且已确认的个人模板，否则在当前工程新建文字块并校准，不要求预先拥有文本预设，身份文字由本人填写，字号、颜色、层级与位置沿完整默认并允许修改。
4. 姓名默认剪映10号、100%缩放、#FF7100；身份7号、85%缩放、#FFFFFF。以1080×1920模板的姓名X=-704/Y=-340、身份X=-400/Y=-500为参考，按人物和画幅校准、统一左对齐并留字幕间距。用户可改字号/颜色/位置，不能为避脸缩到不可读。
5. 姓名和title的位置不能贴近画面边缘。文字本体、描边和阴影必须完整落在画面安全边距内；即使剪映预览中看似完整，也要在导出前用预览窗口放大检查左边缘和右边缘，不得出现姓名或title贴边、裁切或三行实际左边缘不一致。
6. 文字包装完成后生成`字段回读＋实际画面对照`证据：回读主字幕、姓名和title的字体、字号、颜色、对齐和位置；截取身份块开头、时段中部、结束前及代表性字幕画面，交执行标准判定。
7. 已知错误行为：为了让字幕保持单行，擅自把字间距改成`-4`或其他负值。该操作不在本Skill允许范围内，会造成字符重叠和叠字；发现后必须恢复剪映默认值或已确认字幕预设原值，并重新检查全部字幕卡。不能把这类临时判断写成可选优化。
8. 在剪映显示目标平台安全区，逐段检查头顶动态空间。只在执行标准允许时添加顶部主题，优先接近16号；空间不足直接不加。
9. 默认不加BGM。若使用者明确要求添加，只使用独立轨，选松弛、克制、弱节奏音乐，先做静音消失测试，再用同曲同片段A/B确定参数。
10. 接到韩叙视频剪辑 skill明确传入的辅助理解动画要求后，动画主画面与本人动态圆头像默认调用下述间歇圆头像策略，并按原视频声音／文字后期配音分流；只有当次明确指定真人开场、左上角同步圆窗或0039版式时调用其指定方法。按已选[故事型／PPT型方法](动画类型与分镜方法.md)及实际口播列出动画段时间表：`类型与依据 → 对应原话／观点 → 需要看懂的关系／变化 → 分镜动作或信息结构 → 开始／结束时间码 → 真人画面或圆窗`，记录在本对象运行记录中，再制作和放置动画。后期配音未到时只制作画面审看版；未指定段落时选择只听较难理解的环节，故事型以过程变化承接，PPT型以结构图解展开，动画服务于理解，不按固定数量机械铺满。
11. 当次明确指定的真人开场与左上角同步圆窗模式以真人全画面开场，只在选定环节切为动画主画面，同时将原讲解视频缩为以头部为主的左上角圆形动态小窗，与原声同步；该动画段结束后恢复真人全画面。其余已选择本人动态圆头像的动画视频按下述间歇圆头像策略开场与排布。本人当次另有头像位置、形状或不保留头像要求时按当次要求处理。口播时间线与正式字幕保持连续，字幕位于动画上层。
12. 使用者已要求加入动画的真人口播，开头在第一句话完整结束后进入首段动画，通常在第5秒前后；本次明确指定时间点时按指定时间点切入。先确认第一句结束位置，再为紧随其后的实际观点制作开场动画；未指定结束点时按该观点完整表达范围退出，随后接续其他辅助理解段落。此要求同时适用于普通口播局部动画及明确指定的同步圆窗版式，不因首个复杂逻辑较晚才出现而推迟开场动画；未要求动画的普通口播不自动加入。各关键观点分别判断是否需要独立动画；同一视觉机制只有在信息结构相同且有明确重复作用时复用，否则制作同风格、不同信息结构的动画。
13. 动画进入剪映后，逐段回读实际开始帧、结束帧、层级和覆盖内容，并检查入场前一帧、入场、稳定段、退场及退场后一帧；不得出现黑闪、空帧、字幕被遮、错误残留画面或与口播错位。动画返修只让动画轨、正式导出和成片复查失效，不改动已确认口播、声音、字幕、身份和封面。
14. 制作动画前先从当前剪映工程读取身份块的真实出现时段、占用矩形和正式字幕的真实渲染带，把它们写进动画制作约束。1080×1920竖屏工程以底部约520像素作为正式字幕与平台界面的预留参考区，其他画幅按等比例换算；首段动画若与身份块同屏，还必须为身份块单独留空。没有完成这一步的动画素材不得进入时间线。
15. 动画放入剪映后必须在完整合成画面复查，而不是只查看动画素材本身：首段动画检查身份块同时出现的开头、中部和结束前，其余每段检查稳定画面与代表性最长字幕卡。五层逻辑、多层流程或列表页要逐层确认全部文字、箭头和结论都在主字幕上方；空间不足就拆页或精简动画内容。出现任何压字、贴字或重合时，只返修动画轨并重新执行本段检查，不能靠主字幕缩小、负字间距或改变身份块来让位。


### 明确指定时的动画与圆窗制作方法

- 本同步圆窗版式仅在用户明确选择真人开场/左上同步圆窗时采用；不从其他案例推定用户已经采用。选择后依本节保留可编辑人物、动画、字幕及原声映射。
- 先完成内容、用户所选倍速、气口与全部原口播片段的音量、美颜美体，再分出真人开场与动画段。只为统一圆形裁切，可将动画段的已核查原口播片段做为一个可展开的复合片段；不把复合用作掩盖剪点或参数问题，保留源区间映射，不重复叠加音量。
- 启用本结构时，ChatCut用独立MG场景制作动画，正常MP4导出动画背景；剪映中背景放下层，原生圆形蒙版的同步真人放上层，正式字幕与身份保持独立文字轨。沿用这条已跑通路线，不把透明视频导出或新增Pro订阅设为前提。MG代码按当前工具schema使用`function Animation({item})`与`useCurrentFrame`，代码和场景时间表保留可复用。
- 1080×1920版式起始参考：圆窗中心约(230,335)，直径350px，细橙色边框；主字幕中心约(540,1440)。剪映本次圆蒙版字段为X=-310、Y=625、宽高350，口播子片段缩放34%、X=-622、Y=1128，复合父层100%、X/Y为0。这些字段属于不同坐标系，不互换；新素材须按脸的位置回读裁切，不能机械照抄子片段位移。开场原口播保持100%与X/Y为0。
- 字幕沿用第六步第2项的最终字体确认与断句顺序，一次导入定稿并批量设样式；后续少量长卡在当前工程局部拆分，不重建上游，也不反复清空全轨导入。
- 操作文件选择器前先重新绑定并激活该对话框，再使用前往文件夹和绝对路径；失焦先恢复焦点，不重复遍历目录。移动圆窗或动画先锁定无关轨道，按准确帧定位，必要时剪切后在目标帧粘贴；移动后复查开始帧、结束帧、总时长及原声是否重复或空缺。
- 调色只传递到真人原片或圆窗人物层；复制属性时仅勾选调节，避免覆盖已验收的画面位置、圆形裁切或原声音量。已确认同场景调色可用对比5、饱和3、高光-5、阴影3，其余本次为0作起点，仍须按第五步回读代表画面。
- 正式导出前先核对磁盘满足剪映提示的空间要求。成片复查可直接把最终MP4导入剪映素材库，独立预览且不加到剪辑时间线；从首帧正常速度连续播到结束，一次保留起点、中段、尾段和结束状态记录。边界帧与全部字幕的渲染检查可同期完成，不能代替完整实播或实际听辨。

### 动画配音与间歇圆头像策略

动画主画面、文字配音与可选圆头像的完整操作已迁到[动画视频制作Skill](动画视频制作.md)。此处只保留调用入口；普通口播的局部辅助动画继续按本Skill第六步执行。

## 第七步：剪映封面

1. 选择同修订人物帧，建立1080×1920主封面。
2. 主封面保持清楚的两行标题与独立构图，标题内容来自本条主题及本人要求；字体、颜色读取当前有效样式，未指定时采用清晰粗体、首行橙色、次行白色及深色阴影的基础模板。剪映行距字段不等于实际像素空隙；按最终画幅及实际成片判断，不要求作者私有参照图。
3. 显示目标平台安全区，两行分别调整字号，使每一行的实际字宽都约占安全区可用宽度80%。两行不强制同字号；字数较少、字宽较窄的一行应放大，不得为保持同字号而留出明显空缺。完成字宽后，再按执行标准调整文字块中部位置、两行视觉间距和眼睛遮挡。

4. 沿用用户已认可的整体构图；没有历史参照时按本条人物和主题制作实际封面，核对整体层级与手机可读性。已被本用户否定的构图不简单换字复用；视频内头像位置不自动成为封面构图。

## 第八步：最终气口、总检、导出与成片复查

1. 原口播以用户所选速度的最终时间线为唯一基准；后期生成旁白按[动画视频制作Skill](动画视频制作.md)及最新本条声音配置执行，不保留长气口或额外补入语义停顿。原口播按完整接缝清单使用剪映波形、时间尺和语义逐处复核。每句话或半句话结束后都必须与下一句话或半句话`0帧空白`直接相接，不保留0.1秒、3帧或功能停顿；同时确认前后字音没有重叠、重复、抢字或吃字。未达标只修对应剪点，并复核词头、词尾、音节、适用的原片嘴型和受影响字幕，不对循环虚拟口型冒称逐字同步。
2. 导出前先在剪映时间线和预览窗口完成全部可见版式检查：回读实际字体与全局样式，检查字幕位置、单行显示、语义分卡、姓名/title已启用的身份各行左对齐和人脸两侧位置，并确认前七步当前修订检查点有效。开始全条字幕检查前，先用少量代表画面确认预览足够清晰、时间定位准确，再固定窗口和检查路线；按字幕清单成组检查，保存已检查范围、问题及修复后的结果，不每次点击都截图。窗口故障恢复后确认修订未变，从未完成范围继续；只有窗口或时间定位确实变化才重新校准并复查受影响的证据，不重复整条检查。截图只证明文字与画面，不能代替声音听辨。字体、位置、对齐、重叠和安全区等明显问题未通过时不得先导出再检查。
3. 正式导出前按第一步重新检查实际系统/缓存及输出卷的剩余空间预算，未通过不启动导出；资源检查不代替下列设置回读。每个修订只安排一次计划内正式导出，不生成用于发现明显版式问题的诊断MP4。竖屏成片设为1080×1920、MP4/H.264、恒定30fps、SDR Rec.709、约10Mbps、AAC 48kHz/192kbps，不用HEVC；主封面为1080×1920，不交270×480缩略图。只有导出失败、文件损坏、设置错误或成片复查发现必须返修时才再次导出，并记录原因。
   导出窗口按固定顺序设置并确认：分辨率 → 编码 → 格式 → 帧率与色彩 → 视频码率 → 音频 → 输出路径。下游选项可能随分辨率或编码变化，全部设置完成后重新核对整组实际显示值，保存一次完整设置证据再导出，不用曾经填过的数值代替当前状态。一次核对已证明操作无效，就按本Skill止损要求停止同一种点击，交Agent异常恢复；不反复切换输入方法盲试，也不把菜单问题当成需要重新决定参数。
   导出窗口的回车可能直接启动导出。填写名称或参数后用Tab或空白处退出编辑，再核对窗口和整组实际值；检查完成才点击一次导出。若已进入导出中，先确认实际任务、参数与输出文件，不重复发送导出命令；设置符合目标则继续该任务，设置错误才按已有返修条件处理。单独导出SRT时确认视频、音频与GIF导出关闭，只开启字幕，不重复生成视频。
4. 导出只承担两类检查：文件层核对编码、帧率、音频流、黑帧/黑尾和文件损坏；最终成片层从0秒到片尾实际播放。重新打开当前最终MP4、封面、原素材和仍可操作的剪映工程，按执行标准完成1.0倍全片实播、源片对照、工程完整性和质量收据。AI听辨不可用时如实标记跳过，其他可执行项仍须通过。
   播放前安排起点、中段、尾段和结束状态的取证位置，在一次完整播放中收齐；遇到实际质量问题或缺少必需证据才补查对应范围。已完成且修订未变的有效检查不无故重复，必要补查不能代替完整播放或听辨。
   文件检测发现实际容器与目标不符、但音视频编码和画面参数正确时，保留剪映原导出，使用已可用的封装工具仅复制原视频与音频流到目标容器，不重新编码、不改增益或其他剪辑参数。比较修正前后两个编码流的哈希，重新核对容器、完整解码及修正后的最终文件全片播放；没有这些证据就不能用改扩展名代替格式修正。
   打开播放器后先显示实际播放控件，确认从首帧以正常速度进入播放状态，再记录中段、尾段及自然停止的结束时间；只打开文件或发送播放键不算实播。控件隐藏时先恢复可见状态，不盲用旧元素编号；播放器状态、完整解码和实际听辨分别留证。
5. 成片复查若发现错字、单个气口、字幕样式/位置或身份块问题，先按下方返修表局部修复；不能因为需要重新导出就默认重建ChatCut工程、剪映草稿或全部包装。

## 返修影响范围

| 问题 | 返回工具/步骤 | 下游必须重做 |
|---|---|---|
| 内容取舍、重复、调序、素材来源或实际声音画需要改变 | ChatCut第二/三步 | 新ChatCut修订、新剪映草稿，以及真实受影响的下游步骤 |
| 只改字幕显示错字，实际声音画、内容取舍和顺序不变 | 当前可编辑工程的对应字幕卡 | 受影响字幕卡、正式导出与成片复查；不新建ChatCut工程或剪映草稿 |
| ChatCut交接前发现口播片段未统一用户所选倍速 | ChatCut第三步全选口播片段批量修正 | 用户所选倍速时间线的气口、字幕时间和交接检查；不逐片段修改 |
| 交接前已存在长气口 | ChatCut第三步 | 新草稿及受影响下游 |
| 执行标准指出当前最终工程中只有一个或少量气口缺陷 | 当前可编辑最终工程的对应剪点 | 只修对应剪点、词头词尾、嘴型和受影响字幕，再正式导出与复查；当前工程能独立修改时不重建上游 |
| 交接后少量咳嗽、喷嚏、突发叫声或无关画外音遗漏 | 当前可编辑最终工程的对应声音画区间 | 删除中断区间，闭合接缝，同步受影响字幕与后续动画，检查实际剪口、时点、导出与复查；沿用未受影响参数和包装 |
| 人声音量、美颜美体或调色 | 剪映第五步 | 全选口播片段批量修正对应参数、确认作用范围、导出与复查；不逐片段重复输入 |
| 字幕时间、字体或位置 | 剪映第六步对应字幕卡或整条字幕轨 | 局部问题局部改，全局样式问题整轨改；检查受影响时段、导出与复查 |
| 姓名/title或顶部标题 | 剪映第六步对应文字块 | 只修对应文字块及其完整出现时段、导出与复查 |
| 只改封面 | 剪映第七步 | 只重新导出/检查封面，不重导MP4 |
| 只改导出设置或导出文件损坏 | 剪映第八步 | 重导对应媒体并完成最终复查 |

每次返修前记录`变化项 → 引入问题的工具 → 失效项 → 沿用的有效检查点 → 实际重做项`，不默认从头重跑。只有内容取舍、顺序、素材来源真实变化，或当前工程不能安全独立修改目标时，才新建上游工程或草稿；错字、全局参数、文字样式/位置和局部气口等常见问题按表局部处理。

### 返修封面防错卡

- `只改封面`只缩小重做范围，不取消预读和复读；动手前重读第七步和剪辑执行标准第5节。
- 实际操作清单必须写明：`同修订人物帧 → 一个两行文字块 → 两行各自约占安全区80% → 短行独立放大 → 中部 → 水平居中 → 尽量避开眼睛 → 字体/颜色/行距/阴影 → 无正式字幕或其他残留文字`。
- 验收行距时必须看导出后两行主字的实际可见空隙和阴影边界，并与锁定参照并排比较；不得因为字段值为`10`就把过挤的成片判为`PASS`。
- 直播间贴片的顶部留白、顶部常驻标题不是短视频封面依据。若封面标题在左上、顶部或底部，即使表情、字幕残留和遮眼检查通过，也必须先按“中部+水平居中”重做，不得判定`PASS`。

## 交接、停止与清理

- 通过后交付当前修订最终MP4和主封面；使用者未确认前只标`待审看`。
- 提交`可发布`时写入`mp4_ref`、`cover_ref`、`quality_receipt_ref`、`full_playback_ref`、`source_compare_ref`和`project_integrity_ref`，六项指向同一修订。
- ChatCut MCP或剪映必需能力不可用时，按Agent停在当前步，不用未授权外部工具修补成片。
- 用户停止或不采用时，保留原片、工程和本项目记录；不自动移动、删除、归档或上传，清理需用户另行指示。
