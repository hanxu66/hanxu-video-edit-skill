# 脚本操作与数据格式

这些命令由Codex执行，用户通过对话表达需求。先定位只读SKILL_ROOT与可写WORKSPACE，所有补丁、配置、回执与输出在WORKSPACE。下列`python3`只是Mac写法；Windows用[双系统使用](双系统使用.md)中已经运行核验的解释器和PowerShell `&` 调用，不改变系统代码页。路径均使用实际绝对位置，不把尖括号示意原样执行。

## 任务与本条参数

```sh
python3 "<SKILL_ROOT>/scripts/session.py" --workspace "<WORKSPACE>" init
python3 "<SKILL_ROOT>/scripts/session.py" --workspace "<WORKSPACE>" update --scope task --data-file "<WORKSPACE>/task.json"
python3 "<SKILL_ROOT>/scripts/session.py" --workspace "<WORKSPACE>" update --scope overrides --data-file "<WORKSPACE>/settings.json"
```

`task.json`存任务字段，例如`{"mode":"talking-head","source":"实际原片路径"}`；`settings.json`存本条效果，例如`{"speed":1.1,"show_identity":false}`。不能把`overrides`作为task字段包一层；长期偏好才用`--scope profile`。`--data-file`必须在WORKSPACE；失败返回非零，需读错误及received/allowed，不把命令发出当执行成功。找不到素材先核对实际收到路径，不自动猜扩展名。

| 字段 | 合法值 |
|---|---|
| mode | talking-head / talking-head-ppt / talking-head-story / ai-only / interview / user-interview / livestream-clip / livestream-card |
| animation_type | null / PPT型 / 故事型 |
| animation_scope | local / main |
| avatar_mode | none / circle |
| delivery_scope | formal / review；以用户约定为准，不以当前缺少工程自动降级 |
| voice_plan.status | not_selected / ready / declined / silent_preview / intentional_silent |

生成被取消记declined，先保存断点；用户选择静音预览才记silent_preview，使用review范围，不记accepted。intentional_silent必须有voice_plan.user_quote保存用户明确要无声作品的原话。选择音色不等于实际音频已生成，ready时仍核对本条真实录音/生成文件与听辨。

## 复制、解码与声音分别检查

```sh
python3 "<SKILL_ROOT>/scripts/session.py" --workspace "<WORKSPACE>" protect-source
python3 "<SKILL_ROOT>/scripts/check_media_integrity.py" --media "<WORKSPACE>/实际工作原片.mp4" --audio-policy required --ffmpeg "<FFMPEG>" --ffprobe "<FFPROBE>" --report "<WORKSPACE>/source-integrity.json"
```

把本次原片检查报告的绝对路径登记到task.source_integrity。新任务的plan在进入内容剪辑前要求同一源文件哈希及通过的报告；失败保留检查结果并先处理实际问题。用户明确只采用可解码区间时，记录来源和范围授权，另做有源时码的片段并检查，不能继承整片通过。

protect-source只证明复制前后字节一致，返回的media_decodability仍为not_checked。导入前检查实际解码及声明/解码时长，长回放按真实检测范围记录，不以尾帧或一次ffprobe代替全片检查。异常保留原片与副本，说明有效范围，不自动裁去坏段再当完整原片。

媒体检查默认required，须有音轨且并非全零。无声原素材用optional且记录来源；静音预览用silent-preview，明确要无声作品用intentional-silent。只有实际任务符合才能选这些策略，不能为了拿到通过降低要求。工具不判断说了什么、是否清楚或音色正确。

最终视频再用同一工具生成新回执，不复用原片回执。环境review现在要求实际最终媒体和对应哈希报告：

```sh
python3 "<SKILL_ROOT>/scripts/doctor.py" --workspace "<WORKSPACE>" --stage review --source "<WORKSPACE>/当前成片.mp4" --media-check-report "<WORKSPACE>/final-integrity.json" --report "<WORKSPACE>/review-environment.json"
```

doctor的stage_status只覆盖列出的检查，不是完整质量验收；还需当前封面、包装、字幕像素、平台预览、工程、播放和听辨证据。媒体或回执变了就重验，不沿用旧passed。

## 字幕三种数据不要混用

- 分卡清单JSON：`[{"id":1,"text":"测试字幕","start_us":0,"end_us":1000000}]`。微秒整数不是秒；`review_media.py --cards`用此schema，或`{"cards":[...]}`。该工具只查时间/分卡风险，未测字宽/听辨会保留未验证。
- SRT：用户可编辑字幕文本，交付角色`subtitles`；实际内容以最终音频词头时间组织，不能按字数平均分配时间。
- ASS：用于外部字幕重建的样式/时间源，角色`caption_source`，应含`[Script Info]`与`[Events]`。JSON不是ASS，SRT也不能直接交给ass滤镜。`delivery.py rebuild --captions-ass`可指定包内新修订ASS，但不会更新原生剪映工程。

字宽预检计划为非空`[{"id":1,"text":"测试字幕"}]`，允许同时保留上面时间字段。字体配置包含：font_path、font_sha256、font_size_px、canvas_width_px、safe_left_px、safe_right_px、calibrated、calibration_ref，可增加anchor_x_px、scale_x、letter_spacing_px、padding_each_side_px、protected_terms。calibrated只能来自实际原生样张校准，证据不随开源包提供；几何通过不证明语义合理或字体覆盖全部字。渲染配置与完整命令见[字幕批量质检](字幕批量质检与执行记录.md)。

## 原片形式与工具调用

apply_script仅按当前工具支持的删除标记做源话删减；不要直接改写源句。转写听错走当前ASR修正接口。改动后重新读取脚本、时间线和字幕，再生成计划。某些版本删词不会自动删字幕中的旧词。

edit_item、preview_timeline和Motion Graphics接口来自当前连接的软件，先看当前schema与可用操作方法，不把另一宿主的参数当作本机约定。动画先做可编辑属性、长标题、首尾帧与时长的小样；没有实际能力就保存断点，不用源码或静态图称已完成视频。

新任务使用qa_contract=2：进入review/accepted必须提供`deliverables.media_integrity`，与当前video哈希和声音策略匹配。formal交付另要求同revision的九项包装证据与匹配原生工程；缺项不能用手填passed绕过。旧任务读取不自动升级或回改。原生实际效果、听辨和用户采用仍由真实检查/用户反馈确认。
