本Skill维护动画主画面的操作步骤、参数及制作交接；是否通过只读[剪辑执行标准](剪辑执行标准.md)，本Skill不另立通过／失败判定。口播原片上的局部辅助动画仍读[口播剪辑](口播剪辑.md)，不在这里重写普通口播方法。

## 动画类型与调用

接收韩叙视频剪辑 skill绑定的`animation_type`及选择原话，制作前读取[动画类型与分镜方法](动画类型与分镜方法.md)的对应类别。`故事型`归档连续变化、视觉隐喻和角色／物体接力的制作方法；`PPT型`保留此前判断、对比、流程、层级等结构化图解方法。类型选择由本人本次要求或同对象有效记录决定，不按工具、配色或制作难度代选。类型未明确且无可继承记录时，先回到Agent补齐该选择，不铺设动画全片。

此类型方法也供局部动画使用，具体范围、音源、头像与导出仍按本次明确选择和对应主方法执行。

## 两种调用入口

1. **确认稿入口：**接收使用者当前完整稿、采用依据和本次制作要求，从本方法开始，不要求其他Agent或作者状态库。
2. **文字入口：**直接提供稿件时保存全文、内容确认与制作授权。只有文章/主题时，Codex先根据使用者提供的真实材料准备稿件并确认，再制作；不补造选题、拍摄或旧稿已确认的事实。

开工锁定对象、稿件全文及哈希、来源、修订、交付范围、音源、动画类型及选择依据、视觉样式。稿件有占位、截断或明确缺口时只补必要信息；本人已确认的观点不因独立制作再改写。

默认采用包内深底米白橙色动画模板，用户指定新风格时先做必要小样；声音只使用用户本次选择和实际可用的音源，读取[用户配置与声音](用户配置与声音.md)。纯动画默认不加头像；仅明确要求时使用本人提供的对应素材。审看与正式交付按本次范围执行。

## 第一步：稿件与画面方案

1. 读取当前完整稿件；独立调用以已确认稿件为制作依据，不额外要求公众号原文。涉及文章改编时回读对应原文证据，再把稿件按实际语义分段，读取已选[动画类型的方法](动画类型与分镜方法.md)，建立“原稿段落 → 需要理解的关系／变化 → 对应分镜与动作 → 配音段 → 字幕”的对照。公众号原文链接失效时使用已核对的本地全文；缺正文不从标题补造观点。
2. 锁定画幅、已认可样式与头像选择。默认审看版1080×1920、30fps；其他画幅按本次明确要求。正式导出参数引用[口播Skill的正式交付参数](口播剪辑.md)，不在本文件另定一套正式参数。
3. 第一镜头沿用下述已确认的左对齐大标题，醒目清楚；约1至1.2秒后进入核心观点，2至3秒内完成首轮呈现。后续分镜执行已选类型：故事型按内容中的动作与状态变化推进，PPT型按判断、对比、因果、流程或模型组织；两者均保留原文真实关系与实际项数，不统一套四点。PPT型的同组并列概念由主题引出后同时出现，加克制的整体动画；故事型的发生顺序则跟随原声，不为套并列版式打断连续过程。
4. 没有其他画风要求时以本版深底米白橙色模板作为起点；这不是使用者过去已经确认的偏好。具体角色、物体和构图按本条内容设计，不固定简笔造型。用ChatCut可编辑动画和实际资产制作，保留方案并留出字幕与平台安全区；纯动画不套人物美化或身份。
5. 复读剪辑执行标准对应章节，核对方案与稿件关系后继续。

## 第二步：画面与声音小样

1. 已确认的视觉模板与音色沿用其真实采用依据，直接继续本条制作；只为新样式、新声音或新反馈制作代表片段。
2. 新视觉样式选能暴露主要问题的真实内容，在原生工程生成合成预览，检查长标题、复杂关系、最长字幕与适用的圆头像；新声音用同一短稿生成对照试听。两个样本分别保存采用依据，不能把画面认可当成声音认可。
3. 按执行标准完成可执行检查，必要的新审美／新声音判断交使用者；收到对应确认后继续，不扩展未认可候选。模板复用的逐条检查保留，但不重复增加人工确认。

## 第三步：完整配音与去气口

读取[用户配置与声音](用户配置与声音.md)与本条实际选择。已有完整录音先核对全文；生成声音仅用实际可用且本人选择的音色，新声音先做必要试听。按稿件语义选择参考与重点，记录源音频是否已经去气口/加速，应用一次最终用户所选速度，不复制作者音色或表达资料。

1. 读取最新本条声音配置，保存本轮全文快照、哈希、已确认声音参考和`voice_plan_ref`。原录音、已去气口录音、已加速录音分别标记；目标速度只从最新基准读取。
2. 在本人已授权的生成能力中，以同一有效声音参考按完整语义段生成，记录真实支持的参数和本条结果；既有可用录音则先核对全文。只有实际音色或字音需改变时重生成相应片段。音源缺失但画面可做时只保存静音预览与待配音状态。
3. 用全文转写、词时间码、波形和语义核对漏读、重复、专名与错误发音。同音写法可保留原稿并记录核查证据；真正漏字、错音或变声从对应片段修复，不能只改字幕掩盖。句首弱读字缺失时，可生成短引导语后沿词界剪去引导语，保护目标词头，再重新转写核对；原始尝试与裁切区间留在本条记录，成片只保留原稿正文。
4. 去掉几乎全部句间与段间气口，完整保留词头、词尾和必要字音过渡，合并成连续完整配音。只执行一次基准规定的最终倍速；不按固定字速局部减慢，不拖长重点词，不为画面撑时长补静音，不用变调或整条加速掩盖已失真的声音。
5. 保存完整WAV、有效语音时间码和源音频到成片的映射。新音频确定后才锁定最终画面时长；复读标准并记录机器文字核查与本人实际试听各自的状态。

## 第四步：音画与字幕同步

1. 以实际配音及有效时间码为唯一时长基准，顺序放置动画段落，保持一条有效主声音轨；原视频原声模式保持其真实内容与源映射。字幕按完整词组与相对完整语义分卡，不把一个词拆到前后两张卡。
2. 按已确认模板使用白字与清晰深色描边，字幕与动画及适用头像分区。每张字幕以真实字体、字号、显示宽度和手机观看尺寸查看；超宽时按完整词组拆卡，不通过缩字或挤字维持长卡。
3. 从实际原生Viewer读取合成画面，核对开场、语义转折、长字幕、头像入退场和片尾；动画素材属性、音源绑定、时间线总长与有效区间逐项读回，实际像素不因字段正确而省略。
4. 用原生时间线安排声音，动画和字幕跟随声音；语义分段不增加段间空白。帧网格需要尾部补齐时只记录整条末尾不足一帧的尾差，不逐段补齐造成新气口。
5. 本人明确选圆头像时执行下一可选章节；纯动画直接进入封面与导出。复读标准，完成本条实际同步检查。

## 可选本人圆头像

本节承接原口播Skill的“动画配音与间歇圆头像策略”，仅在`avatar_mode=circle`时执行。原视频有声则用对应原声及同修订画面；文字配音则用既有真实口播循环、源声静音，不记录为新稿逐字嘴型同步。横屏成片仅作头像取材时不启动双版本制作。

1. **按来源选择画面。**原视频任务使用当前同修订的已剪画面，露出与原声语义区间同步。文字配音只有用户明确选择真实视频圆窗时才用其提供/授权的稳定说话素材，核对源区间、身份字、字幕和裁切；源声静音，不能声称循环画面与新稿逐字嘴型同步。新片不复制其他任务的媒体ID或固定时码。
2. **圆窗与人物构图。**人物保持较小，保留肩部／上身和适量背景，减弱细小嘴型的可辨程度；只移动圆内视频调整头部，不把人物放大成大头。圆窗由单层视频完全覆盖，外部透明，不用上下背景填充条。代表性自然姿态的头顶距圆顶约为直径的15%至20%，再检查整段动作避免切头。1080×1920样例起点：圆窗左770、上1190、直径220；内部16:9视频高度280、宽约497.78、水平居中、top=-20。其他画幅等比换算，新取材按真实人物位置调整。视频覆盖与人物大小同时通过改变源构图和裁切实现，不为消除露边把人脸强行放大。实际字幕与身份区单独留空；本模式不用同步原口播的左上角大圆窗或真人全画面开场。
3. **间歇出现。**开头默认露出20秒，可按本条节奏在15至20秒内安排；之后默认再在两处内容转折／本人实践段露出，每次约6至8秒，其余时段隐藏。样例实际为0–20、39–47、52–60秒，后两处属于样例内容位置，不硬套所有视频。每次短淡入淡出，30fps起点约5帧；头像不全程常驻，不为每个关键词重新出现。
4. **制作与取材防错。**动画、圆形遮罩、圆内视频缩放／位移、出现区间和正式文字保持可编辑；沿用Agent规定的主工程与交接路线，ChatCut原生MP4仅作为画面审看或取材证据，不冒充剪映正式成片。用原生剪辑sourceIn定位后核对实际源帧；MG素材内部非零播放偏移若未在像素中证实，先用原生裁剪导出已核查的静音短素材，再从短素材0秒绑定圆窗。原视频原声模式的每次露出均保留对应源区间与剪辑后时间线映射，不复用不对应的循环嘴型；公众号文字模式可循环复用核查后的短素材。不得只因偏移字段正确就声称已选到目标区间。调整人物上下位置只改圆内位移，保持已确认圆窗、缩放、时段和动画不变。

按实际配音时间安排每次露出；人物位移只改圆内位移，不扩大成大头像或改变已认可时段。2026-10-08的字幕安全区修正只上移圆窗整体位置以腾出字幕带，圆内缩放、头顶留白与间歇策略保持原值。本人明确要求真正数字人或逐字口型同步时，另行核对该能力与授权，现有循环头像不承担该交付。

## 第五步：封面、导出与复查

1. 主封面独立制作，纯动画用本条主题与已选样式，不强制人物；要求圆头像时只用本人提供且已选的素材。既有构图沿用真实采用依据，无历史参照就制作本条封面校准，不要求私有样例。重新打开检查安全区和手机可读性，含实时字幕/页码/进度线的视频截图不代替独立封面。
2. 保存ChatCut可编辑工程、完整配音、SRT、封面与版本清单。审看版使用ChatCut原生视频导出：MP4、H.264、1080p、时间线30fps，输出路径实际回读。视频渲染与工程编辑使用原生工具，不改成外部拼视频；FFmpeg等音频处理、帧提取和解码核查仅作辅助证据。
3. 确认导出任务已结束且文件写完，再读取完整视频流、帧数、实际画幅、声音与时长，核对导出声轨确实对应当前完整配音。重新打开实际MP4及封面，正常速度全片审听／审看；AI听辨受限时只标记相应缺口，继续可执行的全文、时间码、音轨及画面检查，交使用者判断音色与演绎。
4. 交付MP4审看版、封面、WAV、SRT、可编辑原生工程和当前修订索引；审看交付保留`剪辑中`并记录`review_delivery_ref`，不提交`可发布`。正式范围按韩叙视频剪辑 skill完成可编辑剪映交接与收尾，再由同一执行标准判定；工具阻塞记录在正式交接，不倒推为已完成的原生审看导出失败，不自动购买、充值或升级。
5. 复读[剪辑执行标准](剪辑执行标准.md)，核对真实文件及范围后由韩叙视频剪辑 skill交付；内容、配音、字幕或画面有缺陷时只返对应步骤，并更新实际受影响的下游产物及检查。

## 制作字段与接续

- 开工：`production_form=animation`、`script_ref`、`script_sha256`（当前稿件文件字节哈希）、`script_approval_ref`、`animation_plan_ref`、`scene=animation`、`project_ref`；独立入口另记`entry_mode=standalone`。已确认稿可由韩叙视频剪辑 skill直接登记`剪辑中`，不补造`已拍`。
- 动画选择与分镜：`animation_type`、`animation_type_source`（本人选择原话或同对象有效继承记录）、`animation_scope`、`visual_style_ref`；类型按本人选择使用中文值。`animation_plan_ref`绑定本条原话、分镜、变化／关系、时点、实际资产及必要的隐喻说明，制作与交付记录沿用同一选择。
- 声音与成片：`voice_plan_ref`、`audio_ref`、`srt_ref`、`avatar_mode`、当前工程和导出实际路径。`source_compare_ref`指原稿／原声与最终内容对照，不强制存在真人原片。
- 审看交付：`delivery_scope=review`与`review_delivery_ref`，说明本人待判断的实际范围；正式交付记`delivery_scope=formal`、`formal_handoff_ref`（正式工程交接记录），才提交`可发布`；保留原有全片实播、封面、工程完整性与质量收据要求，以及真实`audio_ref`、`srt_ref`和`voice_plan_ref`。
- 本版仅交付与返修，不接作者台账、自动发布、数据提醒或账号复盘。
- 各对象独立记录读取与复查，不用第一条检查代替全批；软件恢复按韩叙视频剪辑 skill既有上限，从最后成功检查点继续。运行环境、模型和共享声音参考保留可恢复路径，批次中断后先核对文件、哈希及未完成动作，避免重复生成或重复创建工程。
