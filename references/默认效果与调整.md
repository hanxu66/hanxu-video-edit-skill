# 默认效果与调整

默认采用原剪辑方法的完整效果。使用者不需要学参数；说“按默认做”即可。身份姓名/title内容来自使用者，声音、照片、经历和品牌素材不能沿用作者。实际默认参数与无身份内容的样式保存在[default-look.json](../assets/default-look.json)。本条明确要求优先，调整不自动变成以后所有视频的偏好。

| 部分 | 默认与执行依据 | 使用者可以怎样说 |
| --- | --- | --- |
| 节奏/声音 | 1.1倍速；20dB保留为原方法基线，应用前检查素材峰值与现有增益，可能削波则按本条校准，直接设一次、不叠加；听辨独立核验 | 慢一点、声音小一点 |
| 美颜 | 参数快照包含磨皮0.35、美白0.19、祛黑眼圈0.5、瘦脸0.4及其余原预设项目；按JSON完整组执行，不只做这几项 | 磨皮少一点、保留更多皮肤质感、关闭美颜 |
| 美体 | 参数快照包含瘦身0.2、小头/瘦手臂/直角肩各0.1、磨皮0.11、美白0.19 | 不要瘦身、头部不要调整 |
| 画面 | 原方法的画幅、构图与人物位置；在代表明暗画面检查曝光、亮度、肤色和背景 | 人物近一点、画面亮一点 |
| 调色 | 原方法同场景起点：对比5、饱和3、高光-5、阴影3，其余0；不同光线按真实画面校准并记录，脸部泛白时按[局部返修](常见问题与局部返修.md)压高光、补层次，不把套过默认当作检查通过 | 暖一点、颜色淡一点、脸太白了、增加立体感 |
| 主字幕 | 三极宋黑体超粗、剪映13号、白色、深色阴影、非负字间距；单行、无标点，按完整语义分卡；人物下方及平台安全区内 | 字大一点、换颜色、往上一点 |
| 姓名/身份 | 姓名10号、橙色#FF7100；身份7号、白色、缩放85%；左对齐，位于脸侧，和字幕留空隙 | 姓名再大一点、身份移右边、不显示身份 |
| 封面 | 同修订独立封面；两行标题、橙/白分色、粗体和深色阴影，各行按实际字宽校准 | 换标题、调字号/颜色 |
| 动画/导出 | 已选动画类别使用包内完整方法和配色；不为纯口播加动画。竖屏默认1080×1920、H.264、30fps、SDR Rec.709及原音频规格 | 换画风、改横屏 |

## 资源与跨工具复现

以上参数表是普通口播基线。直播回放切片/卡片场景默认1.2倍，姓名/身份起点10/8、顶部主题18（可降16/15）；见[直播方法](直播切片剪辑.md)。访谈从自然1.0倍校准，按各说话人调整音量，不默认把作者脸型和美体参数应用到受访者；见[访谈方法](访谈剪辑.md)。所有调整能力仍保留，用户可通过对话选用或修改。场景默认先于显式个人偏好/本条覆盖，不回改暂停任务。

- 美颜/美体快照包含每个效果的数值、组名与平台资源ID，不只携带“我的预设”名称。先查本机工具是否具备同一效果；在当前测试中不安装或写入全局预设。没有对应能力就登记缺少的项目，不能悄悄跳过并称完整效果。
- 字体只携带名称/平台资源ID及样式，不分发字体文件或模型。用当前可用的正版资源核对实际字体。缺失时由Codex提出具体替代小样，并说明替换项；不能把临时黑体当原默认已复现。
- 剪映字号、缩放、中心坐标与ChatCut/像素坐标是不同单位。姓名参考X=-704、Y=-340；身份参考X=-400、Y=-500仅属于1080×1920剪映模板。按实际人物校准；不把“13号”直接填成13px。
- 当前方法要求身份7号，优先于保存文本预设中的旧8号。复制样式时去掉作者原身份文字与本机路径；保留颜色、字体、阴影等真实样式。
- 文字样式、人物效果、色彩、音量分别记录`目标/实际/证据/未完成项`。只读了参数、选择了预设或保存了文件，都不是实际渲染通过。

## 对话与小样

已给原片和形式时直接登记，不重复问。速度按场景默认，不单独确认。身份未定先做实际小样；使用者明确要显示身份时再合并收姓名/title，不代填作者身份，也不把暂未显示写成长久偏好。信息齐就按完整默认制作，使用者看到实际效果后自然语言修改。

小样覆盖画面/肤色、美颜美体、最长中文与英文词组、姓名/身份和字幕同屏。完整词组不为省事拆开，不用负字间距或缩小字号挤长句。缺原片只能做注明来源的静态排版，不能把它作为完整默认效果或动态剪辑验收。
